fix(review): 统一 Log/Changes 的 Diff Viewer；Changes 改为左右分栏（1.5.1）

两条实机反馈驱动的改动：
1) Log 底部 Diff Preview 的长代码不换行 —— 一行几百字符只能拖横向滚动条；
2) Changes 点文件后差异 inline 插进文件列表 —— 挑文件和看差异挤在一列里。

Diff 正文（Log / Changes 共用同一个 ReviewDiffViewer）：
- 默认自动换行：white-space: pre-wrap + overflow-wrap: anywhere +
  word-break: break-word（不用 normal，避免吃掉缩进）+ tabSize 4；
  换行态下正文容器 overflow-x: hidden，不再留一条没用的横向滚动条。
- 头部新增「自动换行」开关（aria-pressed + tooltip），关掉回到 pre + auto；
  偏好持久化 dsh.review.diffWrap，Log 与 Changes 共用，默认开启。
- 行改成四列网格（旧行号 | 新行号 | +/− | 代码），续行不重复行号与标记，
  align-items: start 让它们停在第一行，整行底色覆盖全部续行。
- 新增唯一的 ReviewDiffViewer：头部/正文/行号栏/hunk/折叠文件头/加载-失败-
  二进制-截断状态只有一处实现；Log 的 DiffPreview、FileDiff、LazyFileDiff
  全部委托给它。

Changes 改为左右两栏：
- 左栏三组与全部动作不变，点文件名只改选中（aria-selected +
  data-staging-selected + 浅强调底色），不碰勾选/暂存/commitPaths。
- 右栏是差异预览，头部简化成 状态+路径+增删 加 [自动换行][关闭]；
  关闭即取消选中，再点从缓存恢复、不重复取数。
- 分隔条可拖动：默认左栏 34%，范围 280px~可用宽度 50%，双击复位，
  持久化 dsh.review.changesFileWidth；左右各自滚动。
- 可用宽度 < 900px 退化成上下堆叠；提交区仍在 main 之外（order 3、
  flex-shrink 0），差异再长也不会被挤出可视区。

测试与文档：
- graph-view 11f/11f2/11f3 改为钉默认换行、开关与持久化、续行不重复；
- overlay-hooks 新增 7b（两页签共用换行偏好 + 字号 uiPx 派生），6b3 加强为
  整份勾选映射前后一致，并补「看差异时提交区仍贴底」；
- staging / lazy-diff 更新为「选中 → 右栏」语义；CDP 冒烟 G2 反转为
  pre-wrap/hidden + 开关断言，新增 G3（Changes 左右两栏）；
- mutation-check 扩到 22 项（pre-wrap 改回 pre、忽略共享偏好、偏好不落盘、
  差异 inline 塞回文件行、关闭不取消选中、点文件名改勾选）；
- README 中英与 RELEASE_NOTES 不再声称「正文 pre 不折行」。
